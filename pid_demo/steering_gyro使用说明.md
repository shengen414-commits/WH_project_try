# steering_gyro 使用说明与实现逻辑

> 对应工程目录：`steering_gyro/`（独立 PlatformIO 工程）
> 功能：读 MPU6050 陀螺仪横摆角速度 → PID 内环 → 控制前轮舵机，实现「高速下外力扰动自动回正走直线」的地基。

---

## 一、代码是什么 / 作用

这份代码实现的是整套方案里的**最内层、最快的一环**：**陀螺仪横摆角速度 PID 内环**。

它要解决的核心问题是：高速行驶时，如果用「摄像头 → 舵机」直接开环控制，会因为视觉延迟 + 舵机滞后产生蛇形、甩尾，走不直。解决办法是让**陀螺仪以高频（200Hz）实时测量车身的横摆角速度（yaw rate），一旦车身有「要转」的趋势，立刻反向打舵把它压回去**。

一句话：**它让小车「想转都转不了」，从而在直线目标下保持笔直。**

代码以独立工程形式给出，可以单独编译、烧录、验证，跑通后再作为模块并入你的完整小车工程。

## 二、文件结构与职责

```
steering_gyro/
├── platformio.ini              # 平台配置:esp32dev + Arduino 框架 + ESP32Servo 依赖
├── include/
│   ├── pid.h                   # 精简位置式 PID 控制器(声明)
│   ├── imu.h                   # MPU6050 陀螺 Z 轴驱动(声明)
│   └── steering_control.h      # 转向内环(声明)
└── src/
    ├── pid.cpp                 # PID 实现
    ├── imu.cpp                 # MPU6050 读寄存器/标定/低通实现
    ├── steering_control.cpp    # 内环:yaw-rate PID → 舵机 PWM 实现
    └── main.cpp                # 入口:串口命令 + 200Hz 调度 + 遥测
```

依赖极简：只用了 `ESP32Servo`（和你现有工程一致）。MPU6050 用 `Wire` 直接读寄存器、PID 自己实现，避免第三方库版本问题，首次编译更稳。

## 三、实现逻辑详解

### 3.1 核心控制公式

整个内环就是一个 PID 闭环，误差定义为：

```
error = r_ref − Kg × yaw_rate

r_ref    : 目标横摆角速度(deg/s)，由外环/遥控给定，直线时 = 0
yaw_rate : MPU6050 测得的实际横摆角速度(去零偏 + 低通后)
Kg       : 陀螺增益(灵敏度)，正负可翻转作用方向
```

PID 输出 `u`（单位是「相对舵机中位的微秒偏差」）叠加到中位：

```
舵机 PWM = 1500 + u     (限幅 1000~2000)
```

**关键效果**：当 `r_ref = 0`（目标直线）时，误差 = `−Kg × yaw_rate`。只要车身出现任何横摆（yaw_rate ≠ 0），PID 就输出反向舵量把它抵消，强制 `yaw_rate → 0`。这就是「外力扰动下舵机自动回正」的机理，直接移植自参考项目 GyroM5。

### 3.2 模块逻辑

**① `pid.cpp` —— 位置式 PID**

- `compute(setpoint, measurement)`：计算 `error = setpoint − measurement`，输出 `P + I + D`。
- **时间由 `micros()` 自动推导**，所以 `Ki`、`Kd` 已经是「每秒」量纲，无需手动除以控制周期。
- **抗积分饱和**：积分项被 clamp 到输出限幅内，防止长时间偏差导致积分爆炸。
- **卡顿保护**：`dt` 超过 0.1s 会被截断，避免断流后微分项突变。

**② `imu.cpp` —— MPU6050 陀螺 Z 轴**

- `begin()`：`Wire.begin()` 初始化 I2C（ESP32 默认 SDA=21/SCL=22），检测器件，唤醒并设量程为 ±500dps（`65.5 LSB/(deg/s)`）。
- `calibrate()`：静止采集 500 次 Z 轴取平均作为零偏 `biasZ_`。**这一步必须在车静止时做**，否则偏置会带偏整个内环。
- `update()`：读原始值 → 减去零偏 → 一阶低通滤波（系数 0.15）。

**③ `steering_control.cpp` —— 转向内环**

- `begin()`：预留硬件定时器，创建舵机对象，设 50Hz、绑定引脚、输出中位；把 PID 输出限幅设为 `[min−center, max−center]`（即 ±500us）。
- `update(yawRate)`：按 3.1 公式算 PID，输出叠加中位后 `writeMicroseconds` 写舵机。
- `setTargetYawRate(r_ref)`：**外环/遥控的接入点**——摄像头/灰度算出的目标横摆角速度、或 RC 转向映射，都从这里设置。
- `disable()`：舵机回中、PID 清零（失能/安全用）。

**④ `main.cpp` —— 调度**

- 无阻塞 `loop()`，用 `micros()` 节流：
  - 每 **5ms（200Hz）** 跑一次内环：读 IMU → `steering.update()`。
  - 每 **50ms（20Hz）** 输出一行遥测：`r_ref, r_meas, pwm_us`。
- 串口命令分发（见下文）。

### 3.3 数据流

```
MPU6050(陀螺Z) ──去零偏──> 低通 ──> yaw_rate ──┐
                                               ├─> PID(error=r_ref−Kg·yaw_rate) ──> PWM=1500+u ──> 舵机
外环/遥控 ──────────────────────> r_ref ───────┘
```

## 四、使用方法

### 4.1 环境与编译

1. 安装 [PlatformIO](https://platformio.org/)（VS Code 插件 `PlatformIO IDE` 或命令行 `pio`）。
2. 打开工程目录 `steering_gyro/`。
3. 编译、烧录、打开串口监视器：

```bash
cd steering_gyro
pio run                 # 编译
pio run -t upload       # 烧录(需先接好 ESP32 的 USB)
pio device monitor      # 打开串口监视器(115200)
```

### 4.2 接线（务必核对）

| 器件 | 引脚 |
|---|---|
| 舵机(DS3120)信号 | GPIO13（`main.cpp` 顶部 `SERVO_PIN`，可改） |
| 舵机电源/地 | 独立供电，地与 ESP32 共地 |
| MPU6050 SDA / SCL | GPIO21 / GPIO22（ESP32 默认 I2C） |
| MPU6050 VCC / GND | 3.3V / GND |
| MPU6050 AD0 | 接地（地址 0x68） |

### 4.3 串口命令

| 命令 | 作用 | 示例 |
|---|---|---|
| `R <deg/s>` | 设定目标横摆角速度（0=直线） | `R 0`、`R 50`、`R -30` |
| `P <kp>` | 设比例增益 | `P 3` |
| `I <ki>` | 设积分增益 | `I 0.5` |
| `D <kd>` | 设微分增益 | `D 0.1` |
| `G <kg>` | 设陀螺增益（负号反方向） | `G 1`、`G -1` |
| `S` | 使能/失能转向（失能回中） | `S` |
| `C` | 重新标定陀螺零偏（保持车静止） | `C` |
| `?` | 打印帮助 | `?` |

> 注意：上电默认**失能**，必须先发 `S` 才会给舵机上电输出，这是安全设计。

## 五、代码作用效果（预期行为）

1. **直线保持**：发 `S` 使能 + `R 0` 后，小车应保持直线；用手掰动车头（制造横摆），舵机会**反向快速打舵**把车头拉回，手松开后回到中位。
2. **目标横摆跟踪**：发 `R 50`，车身会以约 50°/s 的横摆角速度持续转弯（舵机打向对应方向并保持一定角度）。
3. **抗扰动**：行驶中受到地面不平、侧风、后轮打滑等扰动时，陀螺内环在毫秒级内自动修正，远快于纯视觉控制。

## 六、验证方法（分步，每步有判据）

### 步骤 1：确认 IMU 读数正确（不接舵机也行）

- 上电后看串口遥测第二列 `r_meas`。
- **判据**：小车静止时 `r_meas` 应接近 0（±1 deg/s 内）；顺时针/逆时针手动转车，`r_meas` 应随之变大/变小，符号稳定。

### 步骤 2：验证零偏标定

- 静止时若 `r_meas` 明显偏离 0，发 `C` 重新标定（标定期间保持车不动）。
- **判据**：标定后静止 `r_meas` 回到 0 附近。

### 步骤 3：验证方向正确性（关键）

- 发 `S` 使能、`R 0`，用手把车头朝一个方向掰。
- **判据（正确）**：舵机朝**相反**方向打（抵抗你的掰动），车头被「顶」回。
- **判据（错误）**：舵机朝**相同**方向打（助长掰动），越掰越大 → 发 `G -1` 翻转 Kg 符号，再测。

### 步骤 4：调增益验证响应

- 逐步增大 `P`（如 3 → 5 → 8），观察掰头后回正速度。
- **判据**：回正快且不振荡；若出现高频抖动/嗡嗡响，说明 Kp 过大，回调。

### 步骤 5：上路直线验证（里程碑 M3 目标）

- 装车，发 `S` + `R 0`，让车跑起来，观察直线性。
- **判据**：低速下能明显走直，且受外力/路面扰动后能自动修正航向。
- 逐步提高车速，若高速开始蛇形，考虑加 `D`（抑制摆动）或微调 `Kg`。

### 遥测画图（可选）

串口输出为 CSV：`r_ref, r_meas, pwm_us`，可直接用你现有 `PyScripts` 里的 matplotlib 脚本思路画曲线，直观观察内环是否把 `r_meas` 跟踪到 `r_ref`。

## 七、调参指南

| 参数 | 作用 | 过大表现 | 起始值 |
|---|---|---|---|
| `Kg` | 陀螺灵敏度/方向 | 过强→过度修正抖动；符号错→助长转向 | 1.0（先定方向） |
| `Kp` | 响应快慢 | 振荡/嗡嗡响 | 3.0 |
| `Ki` | 消除残余偏差 | 低频摆动/迟滞 | 0.0 |
| `Kd` | 抑制振荡 | 放大噪声、高频抖 | 0.0 |

**调参顺序**：先定 `Kg` 方向 → 调 `Kp` 到快而稳 → 有残余偏差再加 `Ki` → 高速振荡再加 `Kd`。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 上电提示 `MPU6050 not found` | 接线/地址/供电问题 | 查 SDA/SCL、共地、AD0 接地、3.3V 供电 |
| 静止 `r_meas` 不为 0 | 零偏未标 / 标定时车动了 | 发 `C`，保持静止重标 |
| 掰头舵机越打越偏 | Kg 方向反了 | 发 `G -1` |
| 舵机高频嗡嗡抖 | Kp 过大 | 降低 `P` |
| 舵机不动 | 未使能 | 先发 `S` |
| 低速稳、高速蛇形 | 内环响应或机械虚位 | 加 `D`、检查转向连杆旷量 |

## 九、后续接入完整工程

本工程跑通后，把它并入你的 `WH_project_try`：

- 把 `pid.* / imu.* / steering_control.*` 放进现有 `include/` 和 `src/`。
- 在现有 `main.cpp` 的 `loop()` 里，用 `setTargetYawRate()` 接外环：
  - **手动模式**：RC 转向通道映射为 `r_ref`；
  - **自动模式**：摄像头/灰度算出的横向偏差 → `r_ref`。
- 速度环（编码器→电调）作为并列闭环，高速时恒速更稳。
