## 查询与后续接入

`PyScripts/steering_reference.py` 提供纯查询接口，使用分段线性插值，
角度查询返回四舍五入到整数的PWM，不外推、不发送串口命令，也不写入运行中的 `profile.json`。

```python
from PyScripts.steering_reference import load_reference

reference = load_reference()
reference.angle_to_pulse_deg(-22)  # 1200，参考右转22°
reference.angle_to_pulse_deg(17)   # 1700，参考左转17°
reference.angle_to_pulse_deg(26)   # 1850，参考左端点
reference.pulse_to_angle_deg(1400)  # -9.0，估计右转9°
```

这份表不自动接入巡线、IMU或相机独立控制；当前策略仍可直接给出PWM修正。
后续若联合决策输出目标前轮角，可显式调用参考映射，再经过最终输出网关的行程、
速率和超时保护。仅载入本表不会放宽固件行程，参考PWM也不能绕过最终限位。
若落地实测与当前结果不同，可为对应条件单独保存同格式JSON，
通过 `load_reference(path)` 选择；控制增益、工作行程及是否使用这份映射应分别配置。
不要为了迁就当前表而强制调整未来的实车控制结果。

落地后建议重新核对1500直行、同一前轮两侧转角、去程/回程差异及负载下的有效行程。
本次CSV只含一条角度曲线，不能据此推定另一前轮角度、左右轮平均转角或运行中的真实转角。
