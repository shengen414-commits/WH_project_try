# 联合低速控制

左相机负责检测与标定，右相机负责实验录像和即时回放。默认左相机为 `/dev/video0`、右相机为 `/dev/video2`；重新插拔后可通过 `CAR_VISION_CAMERA` 和 `CAR_RECORD_CAMERA` 指定实际设备编号。普通三秒记录保存右相机 JPEG、编码器 CSV 和帧对齐结果。左右相机仍可分别预览，标定时也可用单张截图。

从项目根目录在香橙派上编译 C++ 检测器，再启动后台。已有固件需更新到本次的 `esp32dev` 构建。

```bash
g++ -O2 -std=c++17 PyScripts/native/line_detector.cpp -o PyScripts/native/line_detector
python3 PyScripts/Camera_mit_Rotation_dashboard.py
```

也可通过 `CAR_NATIVE_LINE_DETECTOR` 指向另一个已编译的可执行文件。C++ 进程处理等尺寸灰度图，输出单条直线的候选点和置信度。图像缩放、灰度转换和地面投影复用现有 Python/OpenCV 接口。左相机持续取走硬件帧，最多约 30 Hz 解码，在联合模式中只交给检测器处理最新帧。

1. 在「状态估计与执行器标定」填写轴距、巡线探头间距、安装位置、编码器每计数位移及正向符号。用实测左相机配置完成地面标定，并填写曝光到读帧的延迟。
2. 退出联合观察、独立转向和调试。先架空车轮，点击「开启联合低速测试」，保持静止直到固件确认。界面显示送入联合模式的视觉偏差、角度和年龄。
3. 初始目标速度为零。验证舵机左右方向后，在封闭直线路段由低速开始，输入目标速度并点击「应用目标车速」。固件限制在 0～0.8 m/s，按观测质量和偏差进一步限速。停止使用「关闭转向并归中」或急停。
4. 实验录像先打开右相机，再开启三秒记录或一分钟回放；可以同时进行车速和压力记录。

ESP32 以约 10 ms 节拍读取本地巡线、编码器和 IMU，使用短时姿态历史补偿迟到的视觉观测，计算横摆目标、转角和电调输出。实测轮角参考用于中位附近的近似映射。舵机 PWM 仍为 50 Hz。实验阶段保持 PWM 限幅，正向电调信号仍需验证车辆在有限 PWM 范围内能否可靠起步和调速。

传入视觉观测带设备时间、序号、会话和 CRC；固件检查 150 ms 新鲜度并等待连续有效观测。起步需要有效巡线和相机。观测降级时限速，视觉中断后仅允许短暂依赖有效巡线；路线失效、IMU 失效或目标通信超过 250 ms 时归中停动力，并锁定至手动关闭。目标速度仅由显式的面板操作设置，现有单传感器测试继续使用各自参数。

Linux 后台启动后由独立进程持有串口，速度和压力记录仍使用原有异步队列。硬件相机、图像写盘及控制并发的延迟分布、闭环速度参数与轮角负载响应需要在车上测量；本阶段为低速验证。
